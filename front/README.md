# Dala — фронт

Прототип интерфейса на React 19 + Vite + TypeScript + Tailwind v4.
Данных с реального Docker пока нет: всё живое, но из моков (`src/lib/mockContainers.ts`,
`src/lib/mockLogs.ts`). Когда появятся роутеры FastAPI — меняются только эти файлы и хуки в
`src/state/`.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # проверка сборки
```

## Что уже есть

**Контейнеры** (`src/components/containers/`)

- список с фильтрами по состоянию и поиском по имени/образу/id/порту/сети;
- живые метрики на строку: CPU, память, сеть (rx/tx), диск (read/write) — со спарклайнами истории;
- размер контейнера, аптайм, health, число рестартов;
- действия: логи, старт, стоп, пауза, рестарт, удаление.

**Логи** (`src/components/logview/`) — основная фича

- нижняя док-панель с вкладками, тянется по высоте за верхнюю границу;
- два режима: одна панель (вкладки) и плитка — несколько логов рядом одновременно;
- полноэкранный режим панели (Esc — выход);
- открепление лога в плавающее окно: перетаскивание за шапку, ресайз за все восемь сторон,
  возврат обратно в док;
- в каждой панели: grep с подсветкой, фильтр по уровням (DBG/INF/WRN/ERR), пауза потока,
  автопрокрутка (сама выключается при скролле вверх), перенос строк, метки времени,
  размер шрифта, копирование, скачивание `.txt`, очистка буфера;
- буфер 5000 строк на сессию, в DOM рисуются последние 1200.

## Структура

```
src/
  lib/            форматирование, фильтр логов, генераторы моков
  state/          useDockerMock (контейнеры + метрики), useLogSessions (окна логов)
  components/
    shell/        сайдбар, топбар, заглушки будущих разделов
    containers/   список контейнеров
    logview/      док логов, панель лога, плавающее окно, тулбар, рендер строк
```

> Папка называется `logview`, а не `logs`, потому что в `front/.gitignore` есть правило `logs` —
> папку с таким именем и git, и сканер классов Tailwind пропускают.
